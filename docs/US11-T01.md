# US11-T01 — Contrato público da API

O contrato OpenAPI está em [openapi.yaml](openapi.yaml). As rotas públicas são
`GET /indicadores` e `GET /series`, registradas no Blueprint
`app/api/indicadores.py`. Não exigem login; `/docs` não é criado
automaticamente. O contrato é publicado como arquivo YAML.

A [US11-T03](US11-T03.md) acrescenta o guia HTTP público em `/docs/indicadores`,
com exemplos, tratamento do limite da T02 e evidência de resposta. `/docs`
na raiz continua sem uma interface automática.

## Estado atual e dependências

O backend agora possui persistência versionada para `IndicadorOperacional` e
consulta paginada. Sem valores publicados, a resposta é HTTP 200 com `dados: []`
e total zero. A migração `us11_0015` cria a tabela; os serviços produtores das
dependências US14-T03B e US23-T01 ainda precisam gravar os resultados para que
as consultas retornem métricas calculadas. A API não inventa indicadores com
base em GPS bruto. Cada valor publicado traz sua unidade, janela, versão do
conjunto e qualidade. Percentuais são `%`, espera é `min`, frequência é
`veiculos/h`; a unidade deve ser definida pela especificação de cada indicador.

## Parâmetros

Ambas as rotas aceitam `linha` (código GTFS até 64 caracteres), `sentido`
(`0`/`ida` ou `1`/`volta`), `tipo` (com `indicador` como alias legado),
`parada` ou `trecho` (mutuamente exclusivos), `versao_gtfs_id`, `inicio` e
`fim` (ISO 8601 com fuso), `page` (padrão 1) e `page_size` (padrão 100,
máximo 100). Parâmetros desconhecidos ou repetidos, períodos invertidos e
valores fora dos limites retornam HTTP 400 com `erro.codigo=PARAMETRO_INVALIDO`
e `erro.campo`. Respostas incluem unidade, contagens, versões e qualidade;
`valor` pode ser `null` quando o denominador é zero.

## Exemplos verificáveis no estado atual

Com o backend executando em `http://localhost:5000`, estes pedidos usam as
rotas reais e, enquanto não houver registros publicados, respondem 200:

```sh
curl -i 'http://localhost:5000/indicadores?linha=8000&page=1&page_size=20'
curl -i 'http://localhost:5000/series?indicador=pontualidade&inicio=2026-11-23T00:00:00Z&fim=2026-11-24T00:00:00Z&page_size=20'
```

Resposta esperada (ambos):

```json
{"dados":[],"paginacao":{"page":1,"page_size":20,"total":0}}
```

Exemplo de validação executável contra a rota real:

```sh
curl -i 'http://localhost:5000/indicadores?page_size=101'
```

Resposta: HTTP 400, `erro.codigo=PARAMETRO_INVALIDO`, `erro.campo=page_size`.
Os testes também inserem resultados publicados no banco SQLite de teste e
exercitam paginação e serialização das respostas 200 com dados.

## Verificação

`python -m pytest -q tests/api/test_indicadores_publicos.py` cobre ambas as
rotas, acesso sem credenciais, validações, resultados vazios e publicados,
paginação, serialização e ausência de `/docs` e `/openapi.yaml` servidos
automaticamente. O arquivo OpenAPI é documentação estática versionada; para
interface interativa é preciso uma decisão e implementação separadas. Aplique
a migração antes de subir a API em uma base existente.
