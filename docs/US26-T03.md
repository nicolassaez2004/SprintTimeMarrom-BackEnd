# US26-T03 — Limiar, ausência total e atualização da qualidade

Testes: `tests/indicadores/test_qualidade_publicada_us26_t03.py` (dados sintéticos, SQLite em
memória, exportações em diretório temporário). Base: US26-T01 (`FalhasColeta`). A US26-T02 não
existia em nenhuma branch quando esta validação foi feita.

Fluxo exercitado: ciclos `ExecucaoColeta` → `atualizar_indicadores` / `consolidar_dia` (US23-T03)
→ `gravar_indicador` + `FalhasColeta` → `GET /indicadores`, `GET /series`, `GET /qualidade` →
`GET /downloads/indicadores` (com `versao_dados` e arquivo diário).

## Cenários (janela 12:00–12:15 UTC, intervalo 30 s)

| Cenário | percentual | incompleto | situacao | motivo |
|---|---|---|---|---|
| 30/30 ciclos com dados | 0.0 | false | COMPLETA | — |
| 27/30 (3 sem registro) | 10.0 | false | COM_FALHAS | — |
| 101/1000 sem dados¹ | 10.1 | true | INCOMPLETA | FALHAS_ACIMA_DO_LIMITE |
| nenhum ciclo, jamais | null | null | SEM_EXPECTATIVA | FORA_DO_MONITORAMENTO |
| coleta ativa, 0 ciclos + lacuna aberta | 100.0 | true | SEM_DADOS | NENHUM_CICLO_COM_DADOS |

¹ 10,1% só é representável com denominador 1000; como `denominador = max(esperados, registrados)`,
o teste registra 1000 ciclos na janela.

API e CSV levam o mesmo bloco `qualidade.falhas_coleta`, com o mesmo conteúdo. Ele também confere
com a janela de `GET /qualidade`.

## Correções

- `PublicacaoFrequencia.consultar`: `GET /indicadores?tipo=FREQUENCIA|REGULARIDADE|ESPERA`
  (agregação `janela`) descartava `falhas_coleta`. Agora o bloco gravado é repassado.
  Nas agregações `faixa`/`dia`/`mes` a janela exibida é outra, e o bloco não é repassado.
- `calcular_e_publicar_{frequencias,regularidade,espera}`: `FalhasColeta()` ignorava `agora` e
  `intervalo` da chamada. Com isso, o mesmo registro dizia `coleta` COMPLETA (60 s) e
  `falhas_coleta` INCOMPLETA 50% (30 s).

## Pendências

- O valor do indicador continua publicado quando não há coleta (`FORA_DO_MONITORAMENTO` →
  `incompleto = null`). Quem mostra o aviso deve olhar `situacao` e não apenas `incompleto`.
  Suprimir o valor é decisão de contrato (US26-T02/PO).
- ~~Falta o bloco de falhas nas agregações~~ (revisão 25/11): `qualidade_coleta` (US26-T02) soma as
  contagens dos blocos nas agregações `faixa`/`dia`/`mes` e no mapa territorial.
