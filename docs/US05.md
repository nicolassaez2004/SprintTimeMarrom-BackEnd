# US05-T01/T02 — Acervo de documentos oficiais

Código: [app/documentos/](../app/documentos/) (DocumentService). Migração: `us05_0014`
(`documentos_oficiais`). Testes: `tests/documentos/`.

## Catalogação (T01) — somente interna

Não há rota pública de cadastro, alteração ou exclusão. A equipe técnica usa a CLI:

```bash
python -m app.documentos catalogar --pdf ARQ.pdf --titulo "…" --tipo CONTRATO \
  --data-documento 2026-10-01 --orgao "…" --fonte "https://…" --descoberto-em 2026-11-18T10:00-03:00
python -m app.documentos consultar --id <uuid>
python -m app.documentos original --id <uuid>
```

- O PDF (cabeçalho `%PDF-`) é publicado sem alteração no FileStore com chave
  `documentos/<sha256>.pdf` (`DOCUMENTOS_STORAGE_DIR`, padrão `instance/documentos`). Os
  metadados vão para `arquivos_armazenados` + `documentos_oficiais` na mesma transação.
- Todos os metadados são obrigatórios e informados por quem cataloga; nada é inferido.
- FK `RESTRICT` para o arquivo; `CHECK catalogado_em >= descoberto_em`. Repetir com o mesmo
  PDF e metadados devolve o registro existente.
- **Prazo de 30 dias**: `catalogado_em − descoberto_em ≤ 30 × 24 h`, exposto em
  `prazo.cumprido`. Conferência no Workbench:
  `SELECT id, titulo FROM documentos_oficiais WHERE catalogado_em > descoberto_em + INTERVAL 30 DAY;`

## GET /documentos (T02, também /api/documentos)

| Parâmetro | Regra |
|---|---|
| `tipo` | opcional, valor exato, até 64 caracteres |
| `data_inicio`, `data_fim` | opcionais, `AAAA-MM-DD`, sobre `data_documento`, limites inclusivos |
| `pagina` | opcional, inteiro ≥ 1 (padrão 1) |
| `por_pagina` | opcional, 1–100 (padrão 20) |

Resposta: `{"itens": [...], "paginacao": {"pagina", "por_pagina", "total", "paginas"}, "filtros": {...}}`,
mais recentes primeiro. Cada item traz título, tipo, data, órgão, fonte, datas de descoberta e
catalogação, `prazo` e `arquivo` (id, chave, nome original, tipo, tamanho, sha256).

## GET /documentos/{id}/arquivo

Entrega o PDF original (`application/pdf`, nome original, `ETag` e `X-Conteudo-SHA256` = hash
registrado), conferido pelo SHA-256 antes do envio. Só é localizado pelo id de um documento
catalogado e só se o arquivo for PDF.

Erros: `400 PARAMETRO_INVALIDO` (com `campo`), `404 DOCUMENTO_NAO_ENCONTRADO`,
`503 ARQUIVO_INDISPONIVEL` (ausente, divergente do hash ou não PDF),
`503 CONSULTA_INDISPONIVEL`. Métodos de escrita → 405.

Observação: no MySQL a comparação de `tipo` segue a collation da base (utf8mb4_0900_ai_ci,
sem diferenciar maiúsculas); no SQLite dos testes, diferencia.
