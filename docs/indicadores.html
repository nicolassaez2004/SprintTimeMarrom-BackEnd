Consultas e filtros

  • GET /indicadores: indicadores com unidade, período, versão do conjunto e qualidade.
  • GET /series: pontos temporais com os mesmos metadados e o instante de início da janela.

O GET lê valores publicados; não calcula indicadores a partir do GPS bruto. Sem valores publicados, a resposta é 200 com dados: [].

FiltroFormato e efeito
linhaCódigo numérico da linha, até 16 dígitos. Opcional.
indicadorNome de até 64 letras, números ou _ . : -, sensível a maiúsculas. Opcional.
inicio e fimISO 8601 com fuso; selecionam janelas que cruzem o período. fim deve ser igual ou posterior a inicio.
page e page_sizePágina a partir de 1; tamanho padrão 100, máximo 100. O total de correspondências aparece em paginacao.total.

Exemplo de URL (substitua o endereço pelo da instalação):

http://localhost:5000/indicadores?linha=8000&indicador=pontualidade&page=1&page_size=20

Exemplo ilustrativo de resposta publicada; os números não representam uma medição operacional:

{
  "dados": [{
    "linha": "8000", "indicador": "pontualidade", "valor": 87.5,
    "unidade": "%", "inicio": "2026-11-23T00:00:00+00:00",
    "fim": "2026-11-24T00:00:00+00:00", "versao_conjunto": "exemplo-v1",
    "qualidade": {"cobertura": 0.98, "observacoes": 1250}
  }],
  "paginacao": {"page": 1, "page_size": 20, "total": 1}
}

A unidade acompanha cada valor: não presumir que todo indicador é percentual. Parâmetros desconhecidos, repetidos ou inválidos recebem 400 PARAMETRO_INVALIDO.

60 chamadas por minuto por IP

/indicadores e /series compartilham um orçamento por IP em cada minuto UTC. GET, HEAD e filtros inválidos consomem a cota. A 61ª chamada recebe 429; outra rota ou processo não fornece uma cota adicional. Esta documentação não consome a cota.

O IP é o da conexão. Cabeçalhos enviados pelo consumidor não trocam sua identidade; apenas proxies configurados como confiáveis podem encaminhá-la. Uma rede com vários consumidores no mesmo IP público compartilha o orçamento.

HTTP/1.1 429 Too Many Requests
Retry-After: 30
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 0

{"erro":{"codigo":"LIMITE_EXCEDIDO","mensagem":"Limite de 60 consultas por minuto por IP atingido. Aguarde e tente novamente.","tentar_em_segundos":30}}

Leia Retry-After em segundos, aguarde e limite as novas tentativas. X-RateLimit-Reset informa o fim da janela em segundos Unix UTC. Não tente contornar o limite trocando cabeçalhos de IP. Falha de consulta ou de armazenamento da cota recebe 503, e não uma lista vazia.

A janela é fixa: uma cota pode ser usada no fim de um minuto e outra no começo do seguinte. O resultado não é uma garantia de 60 chamadas em toda janela deslizante de 60 segundos.

Exemplos de consumo

curl

curl -i --get 'http://localhost:5000/series' \
  --data-urlencode 'linha=8000' \
  --data-urlencode 'indicador=pontualidade' \
  --data-urlencode 'inicio=2026-11-23T00:00:00Z' \
  --data-urlencode 'fim=2026-11-24T00:00:00Z' \
  --data-urlencode 'page_size=20'

No Windows PowerShell, pode usar curl.exe em uma linha, sem as barras de continuação do shell Unix.

JavaScript — tratamento limitado de 429

async function consultarIndicadores(base, filtros) {
  const url = new URL('/indicadores', base);
  url.search = new URLSearchParams(filtros);
  for (let tentativa = 0; tentativa < 3; tentativa++) {
    const r = await fetch(url, { credentials: 'omit' });
    if (r.status === 429 && tentativa < 2) {
      const segundos = Number(r.headers.get('Retry-After'));
      if (!Number.isFinite(segundos) || segundos < 1) {
        throw new Error('Retry-After ausente ou inválido');
      }
      await new Promise(resolve => setTimeout(resolve, segundos * 1000));
      continue;
    }
    if (!r.ok) throw new Error(`HTTP ${r.status}`);
    return await r.json();
  }
}

// Exemplo: não é executado automaticamente por esta página.
consultarIndicadores('http://localhost:5000', {
  linha: '8000', indicador: 'pontualidade', page_size: '20'
});

Python — somente biblioteca padrão

import json, time
from urllib.error import HTTPError
from urllib.parse import urlencode
from urllib.request import urlopen

def consultar(base, filtros):
    url = base.rstrip('/') + '/indicadores?' + urlencode(filtros)
    for tentativa in range(3):
        try:
            with urlopen(url, timeout=10) as resposta:
                return json.load(resposta)
        except HTTPError as erro:
            if erro.code != 429 or tentativa == 2:
                raise
            segundos = int(erro.headers['Retry-After'])
            if segundos < 1:
                raise ValueError('Retry-After inválido')
            time.sleep(segundos)

dados = consultar('http://localhost:5000', {
    'linha': '8000', 'indicador': 'pontualidade', 'page_size': 20
})

Ensaio HTTP e seus limites

O registro completo do ensaio inclui cada amostra, ambiente, códigos HTTP e percentil 95, calculado pelo método nearest-rank. O alvo é p95 ≤ 2.000 ms para a amostra medida.

Resultado local: p95 de 61,41 ms, mediana de 36,99 ms e máximo de 132,18 ms. As 100 consultas responderam HTTP 200.

Ensaio local de 23/11/2026: 100 consultas HTTP, quatro clientes concorrentes e dois processos WSGI, sobre 100.000 indicadores sintéticos em SQLite. A medição inclui a conexão TCP e a recepção completa do corpo. A cota foi mantida ativa; os clientes usam IPs reais de loopback, sem forjar identidade.

Este ensaio não mede a Aiven/MySQL nem comprova o mesmo percentil em produção. Não inclui TLS, proxy, internet, falhas ou capacidade máxima. O cache do sistema operacional não foi esvaziado após preparar a base. A aprovação depende da revisão da equipe e de repetir o perfil na implantação real.
