## T01A — sucesso da coleta (`app/monitoramento/sucesso_coleta.py`)

Cada `ExecucaoColeta` é um ciclo (retentativas ficam na mesma linha). Categorias:
sucesso (OK, inclusive sem veículos), falha da fonte (HTTP 5xx, resposta fora do
contrato), falha própria (configuração, credencial, 4xx, banco, processo) e
indeterminada (timeout, conexão, 408/425/429, causa ausente, PARCIAL, EM_ANDAMENTO).

```
esperados   = ⌊período / intervalo configurado⌋
denominador = esperados − falhas da fonte
percentual  = sucessos / denominador        (indeterminados e não registrados ficam)
percentual_maximo = sucessos / (denominador − indeterminados − não registrados)
```

Denominador zero → `percentual = null` com motivo. Limite: `erro` guarda só a
última causa do ciclo; o intervalo esperado é o configurado hoje.

## T01B — sondagem (`app/monitoramento/sondagem.py`, `scripts/sondagem.py`)

```bash
python -m scripts.sondagem --api http://HOST:5000/saude --texto-api servicos \
  --painel http://HOST:5173/index.html --texto-painel Observa
```

Uma rodada por minuto, alvos em paralelo, timeout ≤ 15 s, cada registro em
transação própria (`VerificacaoSaude`: componente, instante, estado, latência,
HTTP, detalhe, rótulo do alvo sem host). O que comprova: API — a rota respondeu
2xx com o texto (com `/saude`, Flask + banco; `/health` só o processo); PAINEL —
a página foi entregue, sem executar JavaScript. Resposta lenta dentro do timeout
é OK com latência; limiar de "DEGRADADO" pendente do PO. Monitor parado ou banco
fora = minutos sem medição (lacuna). Rodar em processo/máquina separados.

## T02 — mês (`disponibilidade_mensal.py`)

Mês civil de São Paulo; mês corrente cortado no último minuto completo.
Por minuto: sucesso se todas as sondagens OK; sem sondagem = lacuna.
Publica percentual observado, cobertura e limites inferior (lacuna = queda) e
superior (lacuna = sucesso). Meta 99% (`>=`): `true` só se mês encerrado e
inferior ≥ 99; `false` só se superior < 99; senão `null` com motivo.
Falha da fonte só é excluída na coleta, nunca da API/painel.
