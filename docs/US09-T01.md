# US09-T01 — Exportação diária dos brutos em Parquet

Código: `app/exportacoes/parquet.py` e CLI `python -m app.exportacoes`.
Migração: `us09_0013` (índice `ix_registros_gps_coletado_em_id`).
Testes: `tests/exportacoes/test_parquet.py`.

## Regras

- **Dia D**: dia civil de `America/Sao_Paulo`, aplicado a `coletado_em`
  (`[D 00:00, D+1 00:00)` local, convertido para UTC). Os instantes continuam em
  UTC no arquivo (`timestamp[us, UTC]`).
- **Leitura**: uma única transação (`REPEATABLE READ` no MySQL), paginada por
  (`coletado_em`, `id`) usando o índice da migração `us09_0013`, sem reler o
  histórico anterior ao dia.
- **Tipos**: inteiros `int64`, coordenadas `float64`, textos `string`; NULL é
  preservado em todas as colunas. `payload` é texto JSON UTF-8, na forma
  normalizada pelo tipo JSON do banco.
- **Publicação**: arquivo temporário no diretório de destino, `fsync`,
  permissão `0644` e `os.replace` atômico. Em erro, o temporário é removido e
  uma publicação anterior do mesmo dia permanece intacta.
- **Metadados por arquivo**: `source`, `source_url`, `license` (`CC BY 4.0`),
  `license_url`, `date`, `date_field`, `period_start_utc`, `period_end_utc`.
- **Brutos**: só `SELECT`; nenhuma linha de `registros_gps` é alterada.
